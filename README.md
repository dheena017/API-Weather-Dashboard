# SkyFetch Weather Dashboard - Part 1

This project is Part 1 of the SkyFetch Weather Dashboard assignment. It demonstrates how to fetch live weather data from the OpenWeatherMap API using JavaScript and Axios.

## Features
- Fetches real-time weather data for a hardcoded city (London).
- Displays City Name, Temperature, Weather Description, and Weather Icon.
- Proper error handling for API failures and missing keys.
- Clean and responsive UI using CSS.

## Setup Instructions

1.  **Clone the repository:**
    - `git clone <repository_url>`
    - `cd API-Weather-Dashboard`

2.  **Get an API Key:**
    - Sign up at [OpenWeatherMap](https://home.openweathermap.org/users/sign_up).
    - Generate a free API Key.

3.  **Configure the App:**
    - Open `app.js`.
    - Replace `YOUR_API_KEY_HERE` with your actual API key.

4.  **Run the Project:**
    - Open `index.html` in your browser (Live Server recommended).

## Technologies Used
- HTML5

- JavaScript (ES6+)
